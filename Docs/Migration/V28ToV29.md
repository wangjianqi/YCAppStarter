# Migration: V2.8 → V2.9

1. Add `Sources/Shared` to app and widget targets.
2. Add `YCAppStarterWidgetsExtension` target.
3. Add App Group entitlement to app and widget extension.
4. Set `NSSupportsLiveActivities=true` in the app Info.plist.
5. Register `WidgetKitPlugin`, `LiveActivityPlugin` and `DynamicIslandPlugin` in `PluginCatalog`.
6. Add V2.9 Remote Config keys.
7. Run:

```bash
python3 Scripts/configure_app_group.py --app-group group.com.yourcompany.yourapp
python3 Scripts/validate_widgets.py
python3 Scripts/ycstarter_doctor.py
xcodegen generate
```
