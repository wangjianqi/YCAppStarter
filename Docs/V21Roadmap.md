# V2.1 Roadmap

推荐下一个版本做这些插件：

1. `FirebasePlugin`
   - Firebase Analytics
   - Crashlytics
   - GoogleService-Info fallback check

2. `RevenueCatPlugin`
   - RevenueCat SDK
   - Offering mapping
   - Entitlement sync
   - Restore purchase

3. `RemoteConfigPlugin`
   - Local provider first
   - Firebase Remote Config optional provider

4. `AIProxyPlugin`
   - Hono + Cloudflare Workers endpoint
   - Streaming API adapter
   - Token usage debug panel

5. `ScreenshotKitPlugin`
   - App Store screenshot helper
   - Device frame config

不要在 V2.1 同时做 Widget、Live Activity、OCR。它们维护成本更高，适合 V2.2 或 V3。
