# YCAppStarter V2.8 — Push + Deep Link + Account Center

## Scope

V2.8 adds operational account infrastructure:

- Push notifications through APNs + Firebase Messaging.
- Remote-config controlled push surfaces.
- Deep link routing through `onOpenURL`.
- Supabase magic-link callback hook.
- Account Center.
- Data export request flow.
- Delete-account request flow.
- Supabase migrations for privacy requests and push devices.
- Worker endpoints for trusted privacy request submission.

## Recommended production flow

1. Configure Firebase and APNs.
2. Upload APNs key in Firebase Console if using FCM.
3. Set `aps-environment` to `development` for local/TestFlight and `production` for App Store builds.
4. Configure Supabase redirect URLs to include the app URL scheme.
5. Run both Supabase migrations.
6. Add an internal admin workflow to process `privacy_requests`.

## Delete-account implementation note

The starter intentionally uses a request-based flow. A client app should not hold service-role credentials and should not directly delete protected auth records. Your backend should:

- verify Supabase bearer token;
- create or update a privacy request;
- delete app-specific data;
- delete storage files if required;
- revoke sessions if applicable;
- remove the Supabase auth user using privileged server credentials;
- mark the request as completed.
