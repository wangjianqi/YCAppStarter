1. Add `Core/RemoteConfig`.
2. Add `Plugins/RemoteConfig`.
3. Add `Modules/RemoteConfig` and `Modules/ReviewSafeMode`.
4. Add `Resources/RemoteConfigDefaults.json`.
5. Add routes `.remoteConfig` and `.reviewSafeMode`.
6. Add `.remoteConfig`, `.reviewSafeMode`, `.featureKillSwitch` to `AppFeature`.
7. Register `RemoteConfigPlugin()` in `PluginCatalog`.
8. Add Firebase `FirebaseRemoteConfig` dependency in `project.yml` if using Firebase.
9. Update `MARKETING_VERSION` to `2.4.0` and build to `240`.
10. Run:

```bash

python3 Scripts/ycstarter_doctor.py

```
