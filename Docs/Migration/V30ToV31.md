# Migration: V3.0 to V3.1

V3.1 is a stabilization migration from feature-rich starter to production-ready starter.

## 1. Regenerate the Xcode project

```bash
xcodegen generate
```

`project.yml` now maps configurations to:

- `Config/Environments/Development.xcconfig`
- `Config/Environments/Staging.xcconfig`
- `Config/Environments/Production.xcconfig`

## 2. Initialize product identity

Prefer one command instead of editing multiple files manually:

```bash
./setup.sh   --app-name "My App"   --bundle-id com.company.myapp   --app-group group.com.company.myapp   --url-scheme myapp
```

This updates the app target, widget target, entitlements, Info.plist values, AppSecrets defaults and shared widget configuration.

## 3. Use strict validation for production

```bash
python3 Scripts/ycstarter.py validate --strict
python3 Scripts/validate_production.py
```

Strict mode blocks warning-level risks such as Google sample AdMob IDs, missing Firebase plist, empty RevenueCat key and default template identifiers.

## 4. Review App Store settings

Before release, replace:

- RevenueCat API key and entitlement configuration
- Firebase `GoogleService-Info.plist`
- Supabase URL and anon key
- AdMob App ID and ad unit IDs
- APNs environment and push topic
- App Group capability in Apple Developer Portal
