# YCAppStarter V2.3 Release Notes

## Added

- App Store Launch Kit plugin.
- AdMob Compliance plugin.
- App Store readiness checklist UI.
- Privacy manifest audit UI.
- Metadata template browser.
- Localization audit UI.
- Baseline `PrivacyInfo.xcprivacy`.
- `Metadata/` App Store Connect templates.
- `Scripts/check_localization.py`.
- `Scripts/check_app_ads_txt.py`.
- `ycstarter_doctor.py` V2.3 checks.

## Changed

- Starter version updated to `2.3.0`.
- Project build number updated to `230`.
- Feature flags now include launch-kit specific capabilities.

## Not Included

- Runtime Google Mobile Ads SDK integration.
- Automated App Store Connect upload.
- Screenshot image generation.

These are intentionally deferred so V2.3 remains a release-preparation layer rather than a large runtime dependency layer.
