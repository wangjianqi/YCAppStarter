# Migration: V2.5 to V2.6

1. Add V2.6 features to `FeatureFlags.swift`:
   - `.backendKit`
   - `.aiProxy`
   - `.aiDebug`
2. Register `BackendKitPlugin` before `AIProxyPlugin` in `PluginCatalog.swift`.
3. Add `AIClient` and `BackendClient` protocol usage in new AI features.
4. Add `RemoteConfigDefaults.json` keys:
   - `ai_enabled`
   - `ai_streaming_enabled`
   - `ai_vision_enabled`
   - `ai_default_model`
   - `ai_daily_quota`
5. Configure the backend:

```bash
python3 Scripts/configure_ai_proxy.py   --base-url https://your-worker.workers.dev   --client-token your-client-token
```

6. Validate:

```bash
python3 Scripts/validate_ai_backend.py
python3 Scripts/validate_remote_config.py
python3 Scripts/ycstarter_doctor.py
```
