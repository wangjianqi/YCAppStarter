# Localization Audit

V2.3 adds `Scripts/check_localization.py` and a Localization Audit UI.

## Run

```bash
python3 Scripts/check_localization.py
python3 Scripts/check_localization.py --strict
```

## Recommended First-Wave Languages

- English
- Chinese Simplified
- Japanese
- Korean
- German
- French
- Spanish

Use this list only if the app can maintain screenshots, App Store metadata and support responses for those locales.
