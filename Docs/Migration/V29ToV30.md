# Migration: V2.9 to V3.0

1. Copy `Config/Environments` into your project.
2. Add `StoreKit/YCAppStarter.storekit` and set it on your local scheme.
3. Add the `YCAppStarterTests` target from `project.yml`.
4. Register `ProductionReadinessPlugin` in `PluginCatalog`.
5. Add routes for production, environment and StoreKit debug pages.
6. Run `python3 Scripts/ycstarter.py validate`.
