# Migration: V2.6 to V2.7

## 1. Add Supabase package

`project.yml` now includes:

```yaml
Supabase:
  url: https://github.com/supabase/supabase-swift.git
  from: 2.0.0
```

## 2. Add entitlements

`Sources/YCAppStarter/YCAppStarter.entitlements` enables Sign in with Apple.

## 3. Configure Supabase

```bash
python3 Scripts/configure_supabase.py \
  --url https://your-project-ref.supabase.co \
  --anon-key sb_publishable_xxx
```

## 4. Run schema

Run:

```text
Supabase/migrations/0001_profiles_membership_ai_usage.sql
```

## 5. Regenerate project

```bash
xcodegen generate
```

## 6. Optional: require auth for AI backend

Set in `Backend/ai-proxy/.dev.vars` or Worker environment:

```bash
SUPABASE_URL=https://your-project-ref.supabase.co
SUPABASE_REQUIRE_AUTH=true
```
