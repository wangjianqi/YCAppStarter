# Metadata Templates

The `Metadata/` directory is the single source for App Store Connect copy.

## Files

- `app_name.md`
- `subtitle.md`
- `keywords.md`
- `description.md`
- `whats_new.md`
- `review_notes.md`
- `privacy_answers.md`
- `screenshot_copy.md`
- `app_store_connect_checklist.md`

## Rule

Do not leave App Store copy only in App Store Connect. Keep the source copy versioned in the repository so every release has traceable metadata.
