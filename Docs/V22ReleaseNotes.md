# V2.2 Release Notes

V2.2 turns YCAppStarter into a commercial app starter.

## Added

- RevenueCatPlugin
- FirebasePlugin
- CrashReporting abstraction
- Paywall template selector
- Minimal paywall template
- Visual Hero paywall template
- Comparison paywall template
- Purchase Debug page
- Analytics Debug page
- Doctor checks for SDK package configuration

## Not included yet

- AdMobPlugin
- RemoteConfigPlugin
- AIProxyPlugin
- SupabaseAuthPlugin
- ScreenshotKit

These are better candidates for V2.3/V2.4.
