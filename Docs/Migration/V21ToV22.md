# Migrating from V2.1 to V2.2

## 1. Update version

`project.yml` should use:

```yaml
MARKETING_VERSION: 2.2.0
CURRENT_PROJECT_VERSION: 220
```

## 2. Add FeatureFlags

Add:

```swift
case revenueCat
case firebase
case admob
case remoteConfig
```

Enable `.revenueCat` and `.firebase` only when you want commercial integrations visible in Debug Panel.

## 3. Add CrashReporting

Add `Core/CrashReporting/CrashReporting.swift`.

## 4. Add plugin folders

```text
Plugins/RevenueCat
Plugins/Firebase
```

## 5. Update PluginCatalog

Add:

```swift
AnyAppPlugin(FirebasePlugin())
AnyAppPlugin(RevenueCatPlugin())
```

Keep them after the core Analytics/Purchase plugins so they can override no-op services.

## 6. Add routes

Add:

```swift
case analyticsDebug
case purchaseDebug
```

## 7. Run doctor

```bash
python3 Scripts/ycstarter_doctor.py
```
